Should You Send Your Resume as PDF or DOCX?

PDF and DOCX are both common resume formats. The right choice depends first on the employer's application instructions and the system through which you are applying. There is no universal file type that is best for every vacancy.

First rule: If the employer specifies PDF, DOCX or another format, follow that instruction.

When PDF is useful

  • It usually preserves fonts, spacing and page layout across devices.
  • It is convenient for recruiters to view without editing the document.
  • A text-based PDF can allow text selection and searching.

Before sending, check that the PDF is not simply a photograph or scan of each page if the employer needs searchable text.

When DOCX may be preferred

  • Some application systems or recruiters specifically request Word format.
  • It can be easier for an employer to make internal notes or process the document.
  • It may be useful when an application portal says it accepts or prefers DOCX.

Open the file on another device if possible and check that fonts, bullets and page breaks remain readable.

How to check a PDF is text-based

  1. Open the exported PDF.
  2. Try selecting a sentence with your cursor or finger.
  3. Copy and paste the text into a plain text editor.
  4. Check that words appear in the correct reading order.
  5. Confirm that no page is blank, cut off or missing.

Use a clear filename

A simple name such as FirstName-LastName-Resume.pdf is easy to identify. Avoid names such as final-final-newest.pdf, unusual symbols or very long filenames.

Final sending checklist

  • Have I followed the employer's format instruction?
  • Is this the latest version of my resume?
  • Does the file open correctly?
  • Are contact details and links correct?
  • Is the file name professional?
  • Have I attached the correct document to the correct application?
